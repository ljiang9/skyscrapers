# skyscrapers 摩天楼谜题

终端里的摩天楼逻辑谜题：生成 4×4 / 5×5 题目并回溯求解。纯标准库。

## 玩法

在 n×n 网格中每行每列填入 1..n（拉丁方）。四周的线索数字表示**从该方向看过去能看到的楼数**——高的楼会挡住后面所有矮的楼。例如一行 `2 1 4 3` 从左看：先看到 2（1 栋），再看到 4（2 栋），3 被挡住 → 线索为 2。

## 用法

```bash
python3 -m skyscrapers                  # 生成 4x4 题目
python3 -m skyscrapers --size 5         # 生成 5x5 题目
python3 -m skyscrapers --seed 42 --show-solution
```

示例（`--seed 7`，4×4，真实输出）：

```
     ·  2  ·  3
   +------------+
 1 |            | ·
 · |            | 2
 2 |            | ·
 · |            | 1
   +------------+
     ·  2  2  1
```

`·` 表示该线索被挖掉（题目故意留白）。

## 实现说明

- 生成：随机拉丁方 → 算出全部线索 → 按 35% 概率挖掉部分线索
- 求解：行排列预过滤（左右线索）+ 列增量剪枝（上下线索在列填满时校验）+ 回溯
- 4×4 毫秒级，5×5 通常秒级

## 真实验证

- `py_compile` 通过
- 手工 4×4 谜题：求解器找到的解与手工答案逐格一致，且 `check_solution` 验证拉丁方+线索全过
- 20 个种子生成的 4×4 / 5×5 谜题全部可解，解均满足拉丁方+线索
- `--show-solution` 内置断言：生成的答案必满足谜题线索

## 已知局限

- 只做 4×4 / 5×5 小棋盘；6×6 以上回溯会明显变慢（行排列 720 种起步）
- 挖掉线索后**不保证唯一解**，求解器只返回第一个解
- 无交互式填涂，只有"看题+对答案"模式
- 需要 Python 3.10+
